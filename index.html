免費上線指南 💡

如何用 GitHub 免費發布這個網站？

不用花錢買伺服器，直接在手機、平板與電腦隨時開啟讓孩子練習！

1

在 GitHub 建立 Repository

登入 GitHub，點選右上角「+」➔「New repository」，取名為 daily-words，設為 Public 並建立。

2

上傳 index.html 與 teacher.png 照片

點選「Add file」➔「Upload files」：
① 將這份網頁程式碼另存為 index.html 上傳。
② 將您的小熊貓照片命名為 teacher.png 一同上傳至同目錄。

3

開啟 GitHub Pages

點選儲存庫上方的「Settings」➔ 左側「Pages」➔ Branch 選擇「main」或「master」➔ 點擊 Save。
約 1 分鐘後即可得到專屬網址！
